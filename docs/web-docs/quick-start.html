Quick start

Two ways to run LightLMS: a local install with PHP and Node, or a single Docker Compose stack. The Docker route is the shorter one.

With Docker

git clone https://github.com/lendradev/lightlms.git
cd lightlms
docker compose up -d

The stack brings up the application, PostgreSQL, Redis, and the queue worker. Open the address the console prints and the setup wizard walks you through the environment check, the first administrator, and whether people may sign up on their own.

The default credentials are in .env.example. Change them before the site is reachable from anywhere but your own machine.

Locally

You need PHP 8.3 or newer, Composer, Node 22 or newer, and pnpm.

git clone https://github.com/lendradev/lightlms.git
cd lightlms

corepack enable pnpm
composer install
pnpm install

cp .env.example .env
php artisan key:generate
touch database/database.sqlite
php artisan migrate --seed

pnpm run build
php artisan serve

The site runs on http://localhost:8000. The seeder creates an administrator, an instructor, and a student, so you can look at every side of the product without making accounts by hand.

Development

Run the PHP server and the Vite dev server side by side, and the front end reloads on every change. 

php artisan serve
pnpm run dev

The commands that must pass

A change is done when the suite and the linters pass. Run all four before you open a pull request.

Command What it checks
php artisan test The whole test suite.
composer run lint PHP style, with Pint.
pnpm run typecheck TypeScript types.
pnpm run lint ESLint rules.
pnpm run build The production bundle builds.

pnpm run format:check reports issues in files that were never formatted. It is only meaningful for the files you touched.
