LightLMS

LightLMS is a self-hosted learning management system. It runs on Laravel and Inertia, it ships as one Docker image, and it does the ordinary work of a school: courses, assignments, quizzes, grades, and certificates.

Quick start Run it locally, or with Docker, in a few minutes. REST API Bearer tokens, endpoints, and the error contract. Assignments and quizzes Attempts, deadlines, marking, and the gradebook. Certificates Completion rules and the public verification page. Deployment Docker, environment variables, and the queue worker. Contributing How the project is built, and where to start.

What it does

  • A setup wizard that checks the environment and creates the first administrator.
  • A course builder with sections, activities, drafts, and publishing.
  • Assignments with attempt limits, deadlines, late policy, and attachments.
  • Quizzes with multiple choice, multiple select, true or false, short answer, and essay questions. Short answers and essays are marked by a person.
  • A gradebook with categories, weights, letter grades, inline marking, and CSV export.
  • An interface in English and Bahasa Indonesia, with a language picker.
  • Certificates of completion with a public verification page.
  • Notifications by in-app message and email, with per-person preferences.
  • A REST API for integrations, authenticated with bearer tokens.
  • An audit log of every privileged action.

What it does not do

LightLMS is deliberately narrow. There is no video hosting, no live sessions, no payment processor, and no marketplace of third-party content. It is a place to put your own courses and to run them properly.

The source is public and the whole application fits in one repository. If something here does not fit your school, change it rather than working around it.
