Configuration

Everything LightLMS needs to run lives in .env. Copy .env.example and change what matters for your installation.

The variables that matter

Variable What it does
APP_KEY Encrypts sessions and cookies. Generate it with php artisan key:generate. Never share it.
APP_DEBUG Set it to false in production. With it on, an error page shows the stack trace.
APP_URL The public address of the site.
DB_CONNECTION sqlite for a small install, pgsql for anything a school would use.
QUEUE_CONNECTION database or redis. A worker has to run for queued jobs to be processed.
CACHE_STORE database or redis.
MAIL_MAILER log writes mail to the log file instead of sending it. Use smtp in production.
FILESYSTEM_DISK Where uploaded files land. Uploaded files are never served directly; a controller checks permission first.

Settings inside the site

Some things belong to the running site rather than to the server. An administrator sets them under Administration → Settings:

  • The name of the site.
  • Whether people may sign up on their own, or only with an invite code.

The setup wizard asks for both. They can be changed later without touching the server.

Roles

There are two kinds of role, and they are not the same thing.

Role Where it lives What it means
Site role users.role student, instructor, or admin. It decides what a person may do anywhere.
Course role course_user.role student, assistant, or instructor. It decides what a person may do inside one course.

Every permission check happens on the server. A hidden button is a convenience, never the control.
