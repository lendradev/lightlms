# Screenshots

Every screen in LightLMS, in both themes. The dark variant of each file carries the `-dark`
suffix.

LightLMS ships a light and a dark theme. The toggle in the header follows the system setting by
default and remembers your choice, so both columns below are the same application in the two
schemes.

Captured at 1440x900 (desktop) and 390x844 (mobile, 2x pixel density).
